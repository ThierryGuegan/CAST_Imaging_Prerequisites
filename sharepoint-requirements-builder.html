CAST Imaging Prerequisites — Requirements Builder

An interactive tool that helps you define the architecture and installation prerequisites for your specific CAST Imaging deployment, instead of handing you a generic, one-size-fits-all checklist.

How to use it

  1. Open index.html in a browser.
  2. Answer the questions on the left (see the table below).
  3. Read the document on the right — it regenerates live as you change your answers.
  4. Print it / save it as PDF, or export just the checklist as HTML for the teams that own each server.

What you are asked

Topic What you choose
Platform & topologyWhere CAST Imaging is installed and how its components are spread across machines.
Deployment scenarioWhich components you need — analysis, Viewer, Dashboards. Five scenarios, from Full to Analysis only, headless.
Project scaleThe size of the deployment, which drives the sizing baseline.
DatabasePostgreSQL hosting model.
Network egressHow the servers reach the internet: direct, via proxy, or air-gapped.
Reverse proxyThe mandatory proxy in front of CAST Imaging.
HTTPSCertificate source.
AuthenticationLocal, SAML or LDAP.
Optional integrationsMCP / AI and CAST Highlight.
Source code accessHow source code reaches the analysis-nodes.
Deployment contextStandard deployment or audit engagement.

What you get

A document built for exactly the profile you selected — not every possible combination:

Section Content
Hardware sizingComposed from your answers rather than a fixed table per scenario. Includes the Kubernetes cluster-node minimum, an architecture diagram of the components and network paths that apply, and the OS/runtime and storage requirements.
Network ports / FQDN allowlistFiltered to the flows your configuration actually needs — no unused rows, no wildcards. Each row is labelled mandatory, conditional, optional or recommended.
Database requirementsCAST Imaging supports PostgreSQL only; matched to your chosen hosting model. Neo4j requirements are added when your scenario includes the Viewer.
Reverse proxy & HTTPS / TLSThe reverse proxy is a mandatory prerequisite (Kubernetes Ingress is preselected on Kubernetes). HTTPS/TLS guidance is matched to your certificate source.
AuthenticationPrerequisites for the exact method you picked (Local / SAML / LDAP), all brokered through CAST's embedded SSO Service and Auth service.
CAST Extend access & licensingSteps adapted for direct, proxy or air-gapped egress.
MCP Server (AI)Prerequisites, shown only if you enable that integration.
Pre-installation checklistBuilt from your actual answers and grouped by the machine or role responsible for each item. Ticks are remembered in your browser.

Printing and export

  • Print / Save as PDF — the whole result. The questionnaire pane and the "generated live" wording are hidden from the print output.
  • Export checklist as HTML — downloads just the checklist, with your profile and your current ticks, as a standalone page you can hand to the teams that own each server.
  • Privacy — everything runs client-side in the browser; no data leaves the page.

Validation notice

Recommendations are derived from CAST Imaging's published documentation structure and standard CAST Software deployment practices. Wherever a specific fact couldn't be verified, the tool says so directly in its own text (e.g. "not independently verified here") rather than presenting a guess as confirmed. Always confirm exact minimum versions, default ports, and sizing against the current doc.castsoftware.com/imaging/install for the CAST Imaging release you are deploying.
